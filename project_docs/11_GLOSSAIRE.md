# Glossaire (simplifié)

- **API** : Interface qui permet aux applications (Web/Mobile) de parler au serveur.
- **JWT** : Jeton d’authentification sécurisé.
- **OTP** : Code à usage unique envoyé par SMS.
- **PIN** : Code personnel choisi par l’utilisateur.
- **Wallet** : Portefeuille électronique interne.
- **Recharge** : Ajout d’argent dans le wallet.
- **Panier surprise** : Pack de produits invendus à prix réduit, contenu variable.
- **Réservation** : Action de bloquer un produit avant récupération.
- **Paiement** : Transaction via Mobile Money ou wallet.
- **Livraison** : Option pour recevoir la commande via un livreur.
- **Broadcast / temps réel** : Notifications instantanées (ex. changement de statut).
- **Design System 2025** : Ensemble de composants UI unifiés.
- **PWA** : Application web installable (offline partiel).
