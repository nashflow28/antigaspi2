  🔄 3. REDUX SLICES CONSUMER (4/4)

  ✅ productsSlice.ts - Gestion produits

  Actions:
  - fetchProducts(filters) - Liste produits avec filtres
  - fetchProduct(id) - Détails produit
  - fetchCategories() - Liste catégories
  - fetchMoreProducts(filters) - Pagination (load more)
  - setFilters(filters) - Mise à jour filtres
  - clearFilters() - Reset filtres
  - updateProduct(product) - Update local (after reservation)

  État:
  {
    products: Product[]
    categories: Category[]
    loading: boolean
    loadingMore: boolean
    error: string | null
    filters: ProductFilters
    currentPage: number
    hasMore: boolean
  }

  ---
  ✅ reservationsSlice.ts - Gestion réservations

  Actions:
  - createReservation(payload) - Créer réservation
  - fetchMyReservations() - Liste mes réservations
  - fetchReservation(id) - Détails réservation
  - cancelReservation(id) - Annuler réservation

  État:
  {
    reservations: Reservation[]
    loading: boolean
    error: string | null
  }

  ---
  ✅ favoritesSlice.ts - Gestion favoris

  Actions:
  - fetchFavorites() - Liste produits favoris (détails complets)
  - fetchFavoriteIds() - Liste IDs favoris (batch check)
  - toggleFavorite(productId) - Ajouter/Retirer favori
  - checkFavorite(productId) - Vérifier si favori
  - optimisticToggleFavorite(productId) - Update optimiste (avant API)

  État:
  {
    favoriteIds: number[] // IDs des produits favoris
    favorites: Product[] // Détails complets favoris
    loading: boolean
    error: string | null
  }

  ---
  ✅ reviewsSlice.ts - Gestion avis

  Actions:
  - fetchReviews({ merchantId, productId, rating, page }) - Liste avis
  - fetchReviewStats(merchantId) - Statistiques avis merchant
  - createReview(data) - Créer avis
  - updateReview(reviewId, data) - Modifier avis
  - deleteReview(reviewId) - Supprimer avis

  État:
  {
    reviews: Review[]
    stats: ReviewStats | null
    loading: boolean
    error: string | null
    currentPage: number
    totalPages: number
    hasMore: boolean
  }
